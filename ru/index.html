Myrtana

Открытый движок Gothic 3 на Unity 6. Он читает вашу копию игры и проходит весь сюжет на новом коде, а ремастер включается по желанию клавишей F7.

Исходники на GitHubКак собрать

Что это

Вся игра

Мир, распорядки NPC, диалоги, квесты, бой, магия, преступления и репутация, торговля, сохранения и интерфейс в стиле оригинала. Всё это Myrtana читает из самой Gothic 3.

Ремастер по желанию

Объёмные облака и новый свет, материалы земли и скал, песок и снег, новые деревья и трава, обновлённые лица и броня, HD-карта. По умолчанию выключен, и игра выглядит как Community Patch 1.75.

Без файлов игры

В репозитории только код и инструменты. Скрипт берёт данные из вашей установки Steam или GOG и собирает игру у вас на компьютере.

Открыто для всех

Код под лицензией MIT. Исправляйте ошибки, переносите механики, экспериментируйте с графикой: pull request'ы приветствуются.

Оригинал и ремастер

На каждой картинке слева Community Patch 1.75, справа ремастер. Нажмите, чтобы увеличить.

Собрать самому

Нужны Gothic 3 с Community Patch 1.75 (Steam или GOG), Windows 10/11 x64, 16 ГБ ОЗУ, видеокарта с DirectX 12, около 120 ГБ свободного места на время сборки и Unity 6000.6.5f1 (версия Personal бесплатна).

  1. Поставьте инструменты: winget install Microsoft.DotNet.SDK.8 Gyan.FFmpeg Python.Python.3.12 и Visual Studio 2022 Build Tools для C++.
  2. Склонируйте репозиторий: git clone https://github.com/szadev/Myrtana.git
  3. Запустите Tools\Setup\setup.cmd. Скрипт найдёт игру и Unity, скачает пакет ремастера (~12 ГБ), сконвертирует ролики, всё импортирует и соберёт G3World.exe. Первый раз это занимает несколько часов.

Вопросы

Это пиратская Gothic 3?

Нет. В Myrtana нет данных игры. Без легальной копии Gothic 3 собрать ничего не получится.

Ремастер обязателен?

Нет. По умолчанию он выключен, а собрать можно и вовсе без пакета ремастера (-NoPack).

На каком языке игра?

Поддерживаются русская и английская Gothic 3: Myrtana берёт тексты и озвучку из вашей установки.

Можно помочь?

Да: открывайте issue или pull request на GitHub. Код — в Assets/G3 (форматы файлов, импорт) и Assets/Myrtana (игровая логика, интерфейс).
